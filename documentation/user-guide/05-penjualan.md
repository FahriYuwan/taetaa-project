# Panduan: Penjualan Marketplace

Halaman ini digunakan untuk mencatat omzet Anda. Setiap penjualan akan memotong stok produk jadi dan menghitung keuntungan Anda secara otomatis.

## Cara Mencatat Penjualan
1. Klik tombol **Catat Penjualan**.
2. Pilih **Marketplace** (Shopee / TikTok / Offline / Affiliate).
3. Masukkan **Order ID** dari aplikasi marketplace (opsional untuk mempermudah audit).
4. Pilih **SKU Produk** yang terjual.
5. Masukkan **Qty** (jumlah unit yang dipesan).
6. **Harga Jual** akan terisi otomatis dari Master SKU, namun Anda bisa mengubahnya jika ada diskon khusus.
7. Masukkan **Biaya / Potongan** (biaya admin marketplace, ongkir yang Anda tanggung, atau biaya lainnya).
8. Klik **Simpan Transaksi**.

## Laba per Transaksi
Sistem akan menampilkan kolom **LABA** di tabel penjualan.
- **Hijau**: Anda untung (Harga Jual > Biaya Bahan + Biaya Admin).
- **Merah**: Anda rugi. Segera evaluasi harga jual atau biaya operasional Anda.

## Filter Channel
Gunakan filter di pojok kanan atas untuk melihat penjualan spesifik dari satu channel saja (misal: "Hanya lihat penjualan Shopee"). Ini berguna untuk membandingkan mana toko yang paling laris.

## Bulk Import
Jika pesanan Anda mencapai ratusan per hari, disarankan menggunakan fitur **Bulk Paste** untuk memindahkan data pesanan dari rekap harian marketplace ke dalam sistem Taetaa.
